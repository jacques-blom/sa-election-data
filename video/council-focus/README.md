# Counted: Who runs your council?

Version 2 is a **20-second, silent, 4:3 demo** at 1440×1080 and 30fps. Large title cards separate full-frame mobile screen recordings. There are no marketing headlines over the demo footage and no audio track.

- Remotion Studio composition: `CouncilFocus`. Open the URL printed by `npm run studio`.
- Watch and download: `/__preview/council-focus/index.html` on the local development server.
- `out/counted-councils-4x3.mp4`: current silent export.
- `out/counted-councils-source.zip`: editable project and source recordings.
- `tweet.txt`: suggested post.

## The cut

| Time | Content |
| --- | --- |
| 0–1.2s | “Who runs your council?” |
| 1.2–4.8s | Tap search, type Tshwane, select the real suggestion and open the council. Played at 1.3×. |
| 4.8–6s | “Watch the balance shift.” |
| 6–10.4s | Tap 2021, tap 2026, switch to Votes %, then highlight DA. |
| 10.4–12.2s | “No majority? Follow the coalition.” |
| 12.2–17.2s | Touch-swipe through Tshwane administrations, open sources and scroll to recorded members and notes. |
| 17.2–20s | “Find your council.” and counted.co.za/councils. |

The eight taps/gestures are two search taps, four chart taps, the coalition swipe, and the sources disclosure tap. Typing and the final vertical scroll are additional real interactions. Tap rings are generated by actual pointer-down events in the recording browser. The horizontal swipe uses native Chrome touch events and is verified to scroll the timeline from 0 to 270 CSS pixels. No result values or government records are altered. Only the Astro development toolbar is hidden.

Recorded 7 November 2026, in an isolated `council-recut` agent-browser session against the existing shared Astro server. Mobile viewport: 480×640 CSS pixels at 3× pixel ratio. Recordings are cropped to focus on each action. Capture timings are in `public/footage/events.json`.

Coalition history is historical context covering November 2021–28 February 2026. The footage retains “Last recorded”, “Pending” and provisional result labels. Its source and cutoff stay visible in the coalition segment. The video makes no claim of a confirmed post-2026 government change.

## Edit and render

```sh
npm ci
npm run check
REMOTION_BROWSER_EXECUTABLE=/opt/google/chrome/chrome npm run render
REMOTION_BROWSER_EXECUTABLE=/opt/google/chrome/chrome npm run poster
npm run source
npm run preview
```

The timeline is in `src/Recut.tsx`. The finalisation script explicitly maps only the video stream and uses `-an`, so exported audio is absent rather than muted. The active project has no music asset or Audio component. The first version is retained only under ignored `out/v1/` and excluded from the downloadable source.

In this checkout, installed dependencies are reused through a local symlink. The source ZIP excludes it and supports `npm ci`. Set `REMOTION_BROWSER_EXECUTABLE` to your installed Chrome path or omit it to let Remotion use its own browser.

Studio runs on local port 3002, privately proxied to HTTPS port 3003. Its log and PID are in `out/studio.log` and `out/studio.pid`. The preview uses the existing Astro server; neither requires restarting that server.

To re-record, run `python3 scripts/record-interactions.py`, then `python3 scripts/prepare-footage.py`. These use the isolated agent-browser session, bundled FFmpeg and a CDP connection to that session for native touch input. Raw captures stay under `/tmp/council-recut-recordings` while recording. The export keeps brief final-frame handles. Space Grotesk’s licence is bundled.
